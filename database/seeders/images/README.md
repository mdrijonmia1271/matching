# Seed product photos

These are the demo catalogue photos, copied onto the `public` disk by
`DatabaseSeeder` so that `php artisan migrate:fresh --seed` always produces the
same browsable store.

Source: [Unsplash](https://unsplash.com). The Unsplash License allows free
commercial use with no attribution required.

They are stand-ins for a demo. Replace them with your own studio photos before
you sell anything: upload a new main image (and gallery) on each product from
**Admin → Products → Edit**, or drop new files here using the same filenames and
re-run the seeder.
